# 🌿 LeafMatch – אפליקציה להחלפת צמחים

אפליקציית ווב בעברית (מימין לשמאל) להחלפת צמחים, ייחורים וזרעים עם אנשים באזור.
**Swipe → Match → Chat → Swap.**

## מה יש בגרסה הזו

- הרשמה קצרה: שם, צבע פרופיל, מיקום (עיר בלבד, בלי כתובת) ורדיוס חיפוש
- מסך גילוי עם כרטיסים: החלקה ימינה (מעוניין), שמאלה (לא בשבילי), למעלה (סופר), או שמירה לאחר כך
- התאמה חכמה: "התאמה מושלמת" כששני הצדדים רוצים את הצמח של השני, ו"הצעת החלפה" כשאין התאמה ישירה
- מסך "יש התאמה!" עם אנימציה
- צ'אט לכל התאמה: הודעות, תמונות, הודעות מהירות, קביעת מפגש במקום ציבורי
- סטטוס החלפה: מדברים, סגרנו, נקבע מפגש, הוחלף, בוטל
- דירוג אחרי החלפה (תקשורת, מצב הצמח, אמינות, כללי)
- הוספת צמח: צילום, "זיהוי" (דמו), סוג הצעה, מצב, כמות, מסירה, פתוח להצעות
- רשימת משאלות עם התראה כשמישהו באזור מציע צמח שחיפשתם
- מפה עם מיקומים משוערים (לשמירה על פרטיות)
- פרופיל: הצמחים שלי, רשימת משאלות, שמורים, היסטוריה והישגים
- סינון לפי מרחק, סוג צמח, סוג החלפה ומסירה

## חשוב לדעת (מה עדיין לא אמיתי)

1. **הנתונים נשמרים רק בדפדפן של כל משתמש.** אין עדיין שרת, ולכן שני אנשים אמיתיים לא יכולים לראות אחד את השני.
2. **שאר המשתמשים הם משתמשי הדגמה** (מאיה, רון, נועה…) והתשובות שלהם בצ'אט אוטומטיות.
3. **זיהוי הצמח מהתמונה הוא הדגמה.** הוא מציע שמות מהקטלוג, ואפשר לתקן ידנית.

השלב הבא כדי להפוך את זה לאפליקציה אמיתית עם משתמשים: מסד נתונים והתחברות (למשל Supabase או Firebase), ושירות זיהוי צמחים (למשל Pl@ntNet).

## איך מעלים לאוויר

כל האתר נמצא בתיקייה `public`. אין צורך להתקין שום דבר.

### אפשרות א': ישר ל-Cloudflare, בלי GitHub (הכי מהיר, 3 דקות)

1. נכנסים ל-https://dash.cloudflare.com ומתחברים (או נרשמים בחינם).
2. בתפריט בצד בוחרים **Workers & Pages**.
3. לוחצים **Create**, בוחרים בלשונית **Pages**, ואז **Upload assets** (העלאה ישירה).
4. נותנים שם לפרויקט, למשל `leafmatch`, ולוחצים **Create project**.
5. גוררים את **התיקייה `public`** (לא את כל ה-zip) לאזור ההעלאה.
6. לוחצים **Deploy site**. אחרי כחצי דקה תקבלו קישור כמו `leafmatch.pages.dev`.

כדי לעדכן בעתיד: נכנסים לפרויקט, לוחצים **Create new deployment**, וגוררים שוב את התיקייה.

### אפשרות ב': דרך GitHub (כל שינוי ב-GitHub מתעדכן אוטומטית באתר)

**שלב 1 – העלאה ל-GitHub**
1. נכנסים ל-https://github.com ולוחצים **New** (מאגר חדש).
2. נותנים שם, למשל `leafmatch`, בוחרים **Public** או **Private**, ולוחצים **Create repository**.
3. בעמוד שנפתח לוחצים על הקישור **uploading an existing file**.
4. פותחים את קובץ ה-zip במחשב, וגוררים את **כל מה שבתוכו** (הקובץ README.md והתיקייה public) לחלון.
5. למטה לוחצים **Commit changes**.

**שלב 2 – חיבור ל-Cloudflare**
1. ב-https://dash.cloudflare.com בוחרים **Workers & Pages**, ואז **Create**, לשונית **Pages**, ואז **Connect to Git**.
2. מאשרים גישה ל-GitHub ובוחרים את המאגר `leafmatch`.
3. בהגדרות הבנייה:
   - **Framework preset:** `None`
   - **Build command:** משאירים ריק
   - **Build output directory:** `public`
4. לוחצים **Save and Deploy**.

> ייתכן שהכפתורים ב-Cloudflare נראים קצת אחרת, כי הם מעדכנים את הממשק מדי פעם. הרעיון נשאר זהה.

## איך משנים דברים בעצמכם

- **שם האפליקציה:** בקובץ `public/index.html` (השורה של `<title>`) ובקובץ `public/js/app.js` (חפשו `Leaf`).
- **צבעים:** בראש הקובץ `public/css/style.css`, תחת `:root`.
- **צמחים, ערים ומשתמשי הדגמה:** בקובץ `public/js/data.js`.

אפשר לערוך קבצים ישירות באתר GitHub: פותחים קובץ ולוחצים על סמל העיפרון.
